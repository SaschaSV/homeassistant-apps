# Alktracker

Privates, deutschsprachiges Alkoholtagebuch für Home Assistant OS. Schnelle Vorlagen,
Jahresübersicht, Kalender, freie Auswertungen und CSV/JSON. Unbekannte Tage bleiben
unbekannt, bis du ihre vollständige Erfassung bestätigst.

Optional: natürliche Texteingabe mit OVHcloud sowie eine ausdrücklich geschätzte
Alkoholkurve. **Modellschätzung – keine Messung und keine Aussage zur Fahrtüchtigkeit.**

Unterstützt: aarch64 (etwa Raspberry Pi 4 mit 64-Bit-HAOS) und amd64.
Das Container-Image ist privat. Vor der Installation einen berechtigten GHCR-Lesezugang
im Supervisor einrichten. Einrichtung und Sicherung: [DOCS.md](DOCS.md).

Updates werden nach automatischen Prüfungen bereitgestellt. Den Installationszeitpunkt
wählst du in Home Assistant. Keine Telemetrie, Werbung oder externen Schriftarten.
