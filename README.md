# Automation AI für Home Assistant OS

Repository für Apps → Repositories:

https://github.com/SaschaSV/homeassistant-apps

Installierbare Versionen werden ausschließlich nach einem freigegebenen, getesteten Release und erfolgreicher anonymer GHCR-Prüfung eingetragen. Dieses Repository enthält nur Installationsmetadaten und Anleitungen. Der Entwicklungsquellcode bleibt in einem privaten Repository; öffentliche Python-Container sind technisch auslesbar.

Die zusätzliche Integration wird separat aus https://github.com/SaschaSV/automation-ai-integration über HACS installiert. Keine API-Schlüssel in GitHub eintragen; OVH-Schlüssel ausschließlich in der App speichern.
